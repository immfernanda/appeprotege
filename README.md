# LP App eProtege

Landing page de captação de leads do App de Gestão eProtege.

- `index.html`: página completa (HTML, CSS e JS em um arquivo)
- `assets/`: logo e imagens

## Configuração
No início do `<script>` do `index.html`, edite o objeto `CONFIG`:
- `whatsapp`: número com DDI e DDD, só dígitos (ex.: 5511999999999)
- `webhook`: URL que recebe os leads em JSON (opcional)
